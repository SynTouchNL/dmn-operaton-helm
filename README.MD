
# Intro
This repository helps setting up an Operaton instance to use in conjuction with DMNStudio including keycloak integration


## Example files
- Dockerfile: Build an image of Operaton including keycloak plugin
- sample-values.yaml: Values file to use with the operaton helm chart -> https://github.com/operaton/operaton-helm/tree/main
- examples/production.yml: Configuration of Operaton
- examples/authorization-changelog.xml: Configuring keycloak autorizations
